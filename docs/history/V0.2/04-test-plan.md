## V0.2 产品与视觉回归
|用例|操作|预期|层级|
|---|---|---|---|
|V01|遍历四个主入口与二级返回|今日/记录/助手/我的；提醒及回顾返回今日，数据/连接返回我的|设备 UI|
|V02|跟随系统、浅色、深色切换并重启|使用对应语义资源，重启跟随系统；无浅色硬编码卡片|设备 UI|
|V03|今日输入草稿，切换记录/助手/我的|草稿保留；保存成功清空、失败保留；时间标签准确|设备/故障注入|
|V04|320vp、600vp、840vp，长中文及放大字体|手机底导航，宽屏侧栏，控件至少48vp；文字换行，键盘不阻断操作|设备 UI|
|V05|无记录、跨日期记录、删除记录|按日期分组；今日仅计当天保留记录；回顾不计算工时|设备 UI|
|V06|对话等待时停止，注入迟到回复/传输失败|保留输入，不写入迟到回复，不重试；明确服务端可能继续执行|本机/设备|
|V07|停止后再次主动发送|新请求可成功；每次传输只释放一次|本机/联调|
|V08|日历未读/拒绝/读取失败|状态真实，有读取入口；不从空数据推断授权结论|设备|
|V09|读屏、键盘焦点、深浅色截图|导航有名称及选中状态，输入焦点可见；状态有文字，核心对比度满足视觉基线|设备 UI|
|V10|加载失败后进入回顾|不把未加载数据当作0条统计；禁止覆盖存储|故障注入|

本机服务测试增加停止请求的两个回归场景。以上 UI 用例是验收要求，执行结果以发布报告为准。
