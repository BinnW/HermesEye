对应 2026-10-07 实现的静态流程说明；不是模拟器验收截图。入口：我的 → 独立业务服务（本地预览）。

连接或离线查看

根地址 / 本次 Token / 私网 HTTP 开关 → 连接 → 校验 serverId 与 workspaceId。身份不符时拒绝合并。已存在的独立副本支持离线查看与新增。

计划与同步

填写今日计划→保存待同步意图→显式同步

已确认对象显示修订；删除产生墓碑。冲突同时显示本机与远端内容，用户选择采用远端或保留本机，以新操作重新提交。快照重建保留未确认编辑。

持久会话

稳定会话标识 + 本次消息 → 保存操作意图 → 请求官方会话 → 显示回执。断线显示结果未知，只允许查询原操作，不自动重发。正在执行时表单禁用。

边界

旧工作区不自动上传。预览入口不替代完整每日计划页，不承诺审批、调度、阅读 Skill、部署或真实后端已验收。
