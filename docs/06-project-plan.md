## 下一步所需资料与决定
1. 家庭 Ubuntu 上 Hermes 的版本、仓库或接口说明、通过 Tailscale 可达地址；凭据只在应用本机填写。
2. 服务端会话、同步、运行事件、停止、部署的实际契约；首批 Coding Agent 适配器与授权策略。
3. 周期工作时段、免打扰、精力量表、日报模板、计划提醒直达策略；这些需单独评审，不默认采用草图示例。
4. 目标鸿蒙设备与可用模拟器、签名；华为运动健康接入资格及数据项。
5. 微信读书来源实际授权、书籍 ID 与周期；其他模块 IMA / 两 Vault 路径与读写确认策略。

## 实施顺序
先联通真实服务器并核验能力 → 会话持久化与增量同步 → 阅读/知识与运行适配 → 自动化记录/日报/提醒 → 全设备矩阵验收。已确认四入口与视觉方向不重复征求确认；新增策略按需求文档逐轮评审。

当前未将未实现功能伪装为成功状态；真实测试和阻塞证据以 [05](05-release.md) 为准。
