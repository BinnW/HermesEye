# 葱丁视觉规范 V0.2

个人品牌 × 鸿蒙应用

> V1.0 继承本文件的视觉 Token、排版与无障碍约束。信息架构和首页优先级由 [V1.0 前端设计](09-frontend-design-V1.0.md) 覆盖：今日 / 项目 / 阅读 / 我的；今日计划 → 项目进展 → 最近在读。下文旧版页面顺序仅作为历史设计参考。


> 以葱青建立识别，以清晰的内容层级降低使用负担。让用户愿意记录，也能看清自己的进展。

## 01｜定位与适用范围

品牌名称：葱丁。主色名称：葱青，#34785A。

品牌气质：理性、亲近、克制、真实在建。内容覆盖工作效率、精力管理、Agent与硬件实践。

应用名称：HermesEye。Hermes 定位为个人学习与效率提升助手，类似贾维斯式的能力伙伴，为理解、思考和行动提供“外骨骼装甲”；HermesEye 是它在鸿蒙设备上的交互与感知界面。以轻量记录、上下文分享、对话、回顾和提醒支持个人成长。葱丁是视觉品牌，不替代应用名称；能力增益的比喻不引入机甲、霓虹或科幻 HUD 装饰。

本规范包含社交内容与应用的共用视觉基础，以及应用专用的交互、组件和状态约定。尺寸、分栏和动效数值为本项目的设计建议，不是鸿蒙 7.0 官方规范或已验证的接口能力；落地时需结合目标 SDK、系统组件和真机验证。

### V0.1 → V0.2

| 保留 | 新增或细化 |
|---|---|
| 葱青、米白、墨黑及暖橙 | 浅色/深色语义色、文字和边界对比度 |
| 真实截图、克制排版、固定签名 | 移动端字号、间距、圆角、触控范围 |
| 统一的语言和内容结构 | 输入、保存、同步、Agent回复、提醒等组件状态 |
| 跨栏目统一主色 | 手机与平板布局、图表规则、交付验收 |

## 04｜字体、间距与形状

### 字体

应用使用系统默认字体，跟随用户字号设置；不为品牌一致性强制加载额外中文字体。社交图文使用思源黑体；代码片段可使用 JetBrains Mono。应用中等宽字体仅用于确有对齐需要的数字或代码。

下列为默认字号设计值。字号以 fp 表达，布局尺寸以 vp 表达；数值需由开发结合实际控件验证，避免直接把设计稿像素当作设备像素。

| 文字角色 | 默认字号 | 字重 | 使用场景 |
|---|---:|---|---|
| 页面标题 | 24 fp | 中粗 | 今日、记录、回顾 |
| 分区标题 | 18 fp | 中粗 | 今日记录、近期提醒 |
| 正文/输入/Agent回复 | 16 fp | 常规 | 长段阅读、输入 |
| 按钮标签 | 16 fp | 中粗 | 记一笔、保存、重试 |
| 辅助说明 | 14 fp | 常规 | 时间、来源、单位 |
| 紧凑标签 | 12 fp | 中等 | 非核心短标签，不承载关键说明 |
| 主数据 | 28–32 fp | 中粗 | 单个重点指标 |

正文建议行高约字号的1.5倍，标题约1.25倍。优先用字号和字重建立层级，同一屏避免同时使用过多字重。重要正文不截断；辅助长标题可两行后省略并提供详情。字号放大时增高容器、换行或改单列。

### 空间与形状

| 项目 | 项目约定 |
|---|---|
| 基础间距 | 4、8、12、16、24、32、48 vp |
| 手机左右边距 | 16 vp，宽屏可增至24 vp |
| 卡片内部边距 | 16 vp |
| 卡片之间 | 12 vp；不同分区之间24 vp |
| 圆角 | 小标签8 vp；输入框/按钮12 vp；卡片16 vp；弹层24 vp |
| 按钮/常规输入控件 | 基准高度48 vp，允许随字号和内容增高 |
| 点击区域 | 最小48×48 vp，图标本体20–24 vp |
| 描边 | 1 vp；焦点环2 vp |
| 分层 | 优先留白、底色和细线；浮层才用轻微阴影 |

避免卡片套卡片、连续多层边框、整页渐变、霓虹光效和装饰性3D。圆角保持有限层级；不要把每一个内容块都做成胶囊。

## 05｜应用组件与状态

| 组件 | 默认表现 | 状态与行为 |
|---|---|---|
| 主按钮 | 葱青底、白字；深色模式按Token映射 | 每个主要操作区域保留一个突出动作；按下加深/提亮；执行中显示进度并防重复提交 |
| 次按钮 | 表面底色、主色文字；需要时显示控件描边 | 用于取消、稍后、查看详情；不与主按钮争夺注意 |
| 文字输入 | 表面底、可辨认轮廓、16 fp正文 | 焦点环主色；错误同时显示文字原因；禁用态说明不可操作原因 |
| 记录卡片 | 日期/时间、正文、保存状态 | 正文优先；编辑、删除放次级操作；分类不作为必填项 |
| 状态标签 | 浅底＋语义色文字＋图标 | “已保存/待同步/失败”均显示文字，不能只换颜色 |
| 底部导航 | 图标＋短标签 | 选中用主色和选中背景；未选中用次级文字色；不依赖颜色独立区分 |
| 开关/选择控件 | 尽量使用系统组件并映射主题 | 显示选中形状或勾选，不只改变背景色 |
| 提示条 | 简短文字，必要时有重试/撤销 | 保存成功轻量反馈；失败提示保留到用户处理或状态恢复 |
| 弹层 | 简短标题、必要说明、主次操作 | 文本输入时避让键盘；关闭前处理未保存内容 |
| 空状态 | 一句话说明＋一个可执行动作 | 示例：“今天还没有记录，先写一句。” |
| 加载状态 | 骨架或局部进度 | 已有内容保留，不以全屏加载反复阻断阅读 |
| 错误状态 | 错误图标＋原因＋恢复动作 | 示例：“暂时无法连接，内容仍在本机。重试”——仅在确已本地保存时使用 |

### 保存与同步的文案必须反映实际状态

| 实际状态 | 显示文案 | 处理方式 |
|---|---|---|
| 正在写入 | 保存中… | 保留编辑内容 |
| 本地保存成功 | 已保存到本机 | 可继续编辑 |
| 已确认服务端保存 | 已同步 | 显示最近同步时间（详情可见） |
| 本地成功、远端未完成 | 已保存到本机，待同步 | 允许后台重试；用户可查看状态 |
| 本地写入失败 | 保存失败，请重试 | 保留当前输入，提供重试或复制 |

自动保存和离线保存属于建议实现能力，必须实现并验证后才能使用相应成功文案。V0.2不把这些能力视为已完成。

## 06｜核心页面设计

以下为建议的信息架构，可随需求调整。手机导航暂定“今日 / 记录 / 助手 / 我的”；数据回顾从“今日”进入，提醒从今日列表和详情进入，先避免入口过多。

### 今日：最先看见“记一笔”

信息顺序：日期与轻量问候 → 记录输入入口 → 今日已有记录 → 最近提醒 → 数据回顾入口。

首屏突出“记一笔”，输入提示为“刚才做了什么？写一句就好。” 不先展示复杂评分、达标率或连续打卡天数。数据卡片最多突出两项，其余进入回顾页。

记录过程允许只有正文。时间由应用补充；分类、精力评分、授权分析均为后续可选操作。自动生成的时间标为“记录时间”，不得直接当作任务开始时间或耗时。

### 记录：以文字时间线为主体

按日期分组，展示记录时间、正文与保存状态；搜索和编辑为次级动作。正文默认完整展示或合理折叠，避免一条记录被多种字段切碎。补记可显示“补记”标识，估算时间写“约”。

首次使用不要求用户先完成目标地图、设置分类或填写完整个人资料。空状态直接进入文字输入。

### 助手：清晰呈现对话和动作

用户消息可用浅青气泡；助手回复使用表面底色或无外框正文。长回复以短段落、清晰小标题呈现，避免过多卡片嵌套。每条回复可显示“AI生成”及必要的数据来源入口。

可执行建议显示为独立操作卡：做什么、何时、影响什么、确认按钮。例如“明天12:00提醒我记录”，按钮为“创建提醒”。只有动作执行成功后才显示“提醒已创建”；建议、生成中、执行中、成功、失败须可区分。

生成中提供停止入口，失败后允许重试且保留原输入。连接状态使用“已连接/连接中/暂时离线”等用户语言；服务器地址、模型和连接日志置于设置或诊断页。

### 数据回顾：先解释数据，再展示趋势

时间范围 → 记录覆盖情况 → 工作类型或趋势 → 原始记录入口。尚未有可信耗时时，优先展示记录条数和出现频次，不据此推断工时占比。

每个指标包含名称、数值、单位、统计范围和来源；估算数据标“估算”，缺失数据显示“暂无数据”，不可用0代替。数据不够时明确说明“记录还不完整，暂不计算占比”。

### 提醒与任务：让下一步明确

列表显示内容、触发时间和状态。主要操作为完成，次级操作为稍后提醒。状态使用“待处理/已完成/已暂停”等短词；逾期不默认大面积红色，只有真正错误或风险才用红。

### 我的：集中管理与连接

顺序建议：个人偏好 → 显示模式 → 数据来源与权限 → Agent连接 → 数据导出与其他设置。每种数据源显示已连接、未授权、更新失败等实际状态，并提供解释和恢复入口。

## 07｜图标、图表与动效

图标采用一套统一的简洁线性图标，24 vp基准、约2 vp视觉线宽。不得混用多套线宽和透视风格。关键操作配文字，状态配可辨识形状。表情符号可用于品牌内容中的偶尔表达，不作应用功能导航主图标。

图表默认葱青为主序列、信息蓝为第二序列，第三序列可用深橙；深色模式使用相应浅色Token。暖橙原色只作辅助区域或带深色轮廓的标记。线条、点形或虚实线区分序列，不能仅靠红绿对照。

优先折线图、水平条形图；不使用3D图表。柱形图从零起点；折线图如截断纵轴必须清楚标注范围。图中直接标单位与时间范围，图表附简短文字结论或可访问的数据列表。

动效建议：按压反馈120–160ms，局部展开180–240ms，页面转场约240ms；这些是品牌节奏建议。优先使用系统转场，尊重减少动态效果设置。录入与保存不添加庆祝动画、强制等待或打卡惩罚。

## 08｜手机、平板与无障碍

使用容器可用宽度而非设备型号决定布局。建议以600 vp、840 vp为初始设计断点，真机测试后调整：

| 可用宽度 | 建议布局 |
|---|---|
| 小于600 vp | 单列，底部导航 |
| 600–839 vp | 保持阅读区适度宽度；空间不足仍单列；可试导航侧栏 |
| 840 vp及以上 | 列表＋详情两栏；侧栏导航；输入/对话主体建议限制在约720 vp以内 |

适配系统安全区域、键盘、横屏、分屏和折叠后窗口变化。跨布局保持当前草稿、选中项和阅读位置。大字号时允许布局重新排列，不能依靠固定高度裁切内容。

本项目参考WCAG对比度要求作为设计验收基准：普通文字至少4.5:1，必要控件边界、状态图形等至少3:1。为了简化原生字号对应问题，核心文字统一按4.5:1校验。颜色之外同时提供文字、图标或形状；装饰线不承担唯一的交互识别职责。

已按不透明sRGB色值计算的典型组合（显示为两位小数，判定按未四舍五入值）：

| 前景 / 背景 | 对比度 | 结论 |
|---|---:|---|
| 白字 #FFFFFF / 葱青 #34785A | 5.28:1 | 可用作按钮正文 |
| 葱青 #34785A / 米白 #F5F2EA | 4.72:1 | 可用作正文强调 |
| 次级文字 #637168 / 米白 #F5F2EA | 4.59:1 | 可用，避免再降低透明度 |
| 暖橙 #E98B42 / 米白 #F5F2EA | 2.28:1 | 不用作正文或唯一状态图形 |
| 深橙 #96501C / 浅橙 #FFF0E2 | 5.44:1 | 提示文字可用 |
| 控件边框 #75857A / 米白 #F5F2EA | 3.48:1 | 可承担控件轮廓 |
| 深字 #13241B / 夜间主色 #80C7A3 | 8.19:1 | 深色模式主按钮可用 |
| 夜间次级文字 #AAB8AF / 卡片 #1D2521 | 7.61:1 | 深色模式辅助说明可用 |

这些计算仅覆盖列出的纯色组合，不代表整款应用已通过无障碍验收。实际透明度、图片背景、字体、焦点、读屏和放大布局均需逐页测试。

参考：[W3C文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[W3C非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

## 09｜品牌内容与应用共用的表达

| 场景 | 保持统一 | 按媒介调整 |
|---|---|---|
| 社交图文封面 | 米白底、墨黑标题、葱青重点、右下签名 | 根据画幅重新排版，不直接拉伸或裁切 |
| 知乎长文配图 | 同一配色、图表和注释风格 | 以可读宽度与正文节奏组织信息 |
| 视频封面/字幕 | 同一标题逻辑、主色和标识 | 字幕优先白字深底，安全区按实际平台预览验证 |
| 应用 | 主色、图形气质、语言和数据表达 | 使用系统字体、系统交互与语义状态 |

封面保留“栏目名/编号＋一句具体观点＋真实素材＋葱丁签名”。照片保留自然色；不把每张图强行染绿。应用内品牌签名只在启动、关于等合适位置出现，不在每张功能卡片重复水印。

品牌标识暂采用“葱丁”字标加一个简单切片方形符号。此处仅定义方向，不视为已交付最终Logo或应用图标。图标需要单独完成小尺寸辨识、深浅背景和系统遮罩测试。

语言使用短句、具体动作和真实状态。记录页以鼓励开始为主，避免绩效式措辞：

| 使用 | 避免 |
|---|---|
| 写一句就好 | 请完整填写所有字段 |
| 今天还没有记录，记一笔吧 | 今日打卡失败 |
| 已保存到本机，等待同步 | 一切已完成（未确认远端状态时） |
| 这条建议基于最近3条记录 | AI已精准掌握你的工作状态 |
| 记录还不完整，暂不计算占比 | 用缺失数据生成精确效率分数 |

## 10｜设计与开发交付标准

建议先完成五个样板：今日（含输入）、记录详情、助手对话与动作确认、数据回顾、提醒列表。先用真实长度的文字检查，再扩展其他页面。

每个页面至少交付：浅色默认态、深色默认态、空状态、加载或保存态、失败恢复态，以及适用的大字号/宽屏布局。涉及同步、权限或Agent执行的页面增加对应状态。

验收清单：

- [ ] 主色始终来自统一Token，无分散硬编码。
- [ ] 常用文字、状态和控件在实际背景上的对比度符合约定。
- [ ] 记录入口一眼可见，只有正文也能完成一次记录。
- [ ] 普通文字、长中文、日期和长任务名称不会重叠或越界。
- [ ] 大字号、横屏、平板分屏、键盘弹出时仍可完成核心任务。
- [ ] 保存成功、同步成功和Agent任务成功使用各自准确的状态文案。
- [ ] 网络或写入失败时保留输入，并有明确恢复动作。
- [ ] 缺失、估算、AI生成的数据均可识别，图表能追溯来源。
- [ ] 关键控件可被读屏理解，焦点可见，状态不只依赖颜色。
- [ ] 图文封面与应用截图放在一起时，配色与语言能够识别为同一品牌。
