# HermesEye · 视觉与交互规范

## 方向：安静的个人工作台
米白底色、深墨绿主色、少量暖金点缀。视觉强调“属于自己的数据和秘书”，减少群聊和办公平台的噪声。首版使用原生组件，无远程字体、无装饰性图片依赖。

## 信息架构
- 今日：日期、秘书引导卡、真实统计、连接摘要、最近记录。
- 对话：上下文预览入口、会话列表、输入框和发送状态；不预置虚构秘书回复。
- 数据：个人记录表单/列表；当日日历与设备快照；权限状态和采集时间。
- 任务：任务标题、时间、每天/工作日选项；注册系统提醒、取消、手动向秘书执行。
- 设置：服务地址、模型、临时 Token、局域网开关、连接检测、隐私说明。

## 关键状态
初次打开：无记录、无任务、未连接；提供明确下一步。读取失败：显示权限/设备能力提示，可重试。网络中：按钮禁用并显示处理中。超时：提醒服务器可能仍在执行，避免自动重试。删除：本地记录与会话清除需明确操作；系统提醒取消失败保留原记录。保存失败：保留编辑内容，不显示成功。上下文快照过期：清除选择并要求刷新。
