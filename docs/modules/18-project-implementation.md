## 2026-10-09 · 首轮设计与实现

### 用户要求与实施取舍

用户明确将学习、健身、效能提升计划按项目管理，持续与 Hermes 交互达成目标；未来通过 HermesEye 构建远程 multi-agent 软件项目。本轮承担详细需求、前端/交互设计与代码开发，完善过程文档；**不在开发过程中编写测试用例**。遵循该明确指令，未新增或修改自动化测试文件，仍执行既有门禁，未降低覆盖率阈值。

项目采用共同目标骨架，类型不绑定虚构进度算法；阶段成果、每日事务和目标达成分别记录。远程构建完整描述计划、分工、事件、审批、成果、部署与恢复，当前没有执行端协议支持，因此本轮仅开放软件项目需求讨论。

### 实现清单

- `core/Workspace.ts`：Project可选扩展字段、旧数据兼容、保存校验、生命周期、里程碑、复盘及摘要规则。
- `components/ProjectPanel.ets`：项目表单、概览、里程碑、复盘、确认达成/归档；按空间与项目保存进程内草稿。
- `pages/Index.ets`：列表检索、状态筛选、首页进行中摘要、组件集成、准备Hermes新需求草稿；继续已有会话仍复用原需求。
- 语义主题沿用；新增组件固定文案进入string资源。原任务编辑/日期逻辑未改变。
- `docs/design/projects/index.html`：独立可交互评审原型，示例数据明确标注，仅浏览器演示，不向Hermes发送。
- 新文档17/18与AGENTS导航同步；未覆盖用户既有V2设计和每日计划未提交改动。
